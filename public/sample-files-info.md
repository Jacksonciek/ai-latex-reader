# Sample Files untuk Testing

## Sample Template PDF
Untuk membuat file template sample, Anda perlu membuat dokumen PDF yang berisi:

### Template Structure:
1. **Title Page**
   - Judul dokumen
   - Subtitle
   - Nama penulis
   - Institusi
   - Tanggal

2. **Table of Contents**
   - Daftar isi dengan nomor halaman

3. **Main Sections:**
   - Executive Summary / Ringkasan Eksekutif
   - Introduction / Pendahuluan
   - Main Content / Isi Utama
   - Analysis / Analisis
   - Recommendations / Rekomendasi
   - Conclusion / Kesimpulan

## Sample Document PDF
Buat dokumen PDF yang berisi contoh laporan pemerintah dengan struktur:

### Document Content:
1. **Header Information**
   - Kementerian/Lembaga
   - Nomor dokumen
   - Tanggal

2. **Content Sections:**
   - Latar belakang program
   - Implementasi kebijakan
   - Data statistik
   - Evaluasi program
   - Tantangan yang dihadapi
   - Rencana tindak lanjut

## Cara Membuat Sample Files:

### Untuk Template:
```
Buat dokumen Word/LibreOffice dengan struktur di atas, 
kemudian export ke PDF dengan nama 'sample-template.pdf'
```

### Untuk Dokumen:
```
Buat beberapa dokumen laporan pemerintah dummy,
kemudian export ke PDF dengan nama seperti:
- 'sample-document-1.pdf'
- 'sample-document-2.pdf'  
- 'sample-document-3.pdf'
```

## Contoh Content untuk Dokumen Pemerintah:

**LAPORAN EVALUASI PROGRAM DIGITALISASI PELAYANAN PUBLIK**

KEMENTERIAN DALAM NEGERI
Nomor: 123/Eval/2024
Jakarta, 15 Januari 2024

1. PENDAHULUAN
Program digitalisasi pelayanan publik telah dilaksanakan sejak tahun 2022 dengan tujuan meningkatkan kualitas dan efisiensi layanan kepada masyarakat.

2. IMPLEMENTASI PROGRAM  
Hingga akhir 2023, telah berhasil didigitalisasi 75% layanan publik di tingkat kecamatan dan 85% di tingkat kabupaten/kota.

3. HASIL EVALUASI
- Tingkat kepuasan masyarakat meningkat 40%
- Waktu pelayanan berkurang 60% 
- Pengurangan penggunaan kertas 80%

4. TANTANGAN
- Keterbatasan infrastruktur IT di daerah terpencil
- Resistensi terhadap perubahan dari sebagian aparatur
- Kebutuhan pelatihan SDM yang intensif

5. REKOMENDASI
- Peningkatan investasi infrastruktur IT
- Program pelatihan berkelanjutan
- Insentif untuk adopsi teknologi

6. KESIMPULAN
Program digitalisasi telah menunjukkan dampak positif signifikan dan perlu dilanjutkan dengan perbaikan pada aspek infrastruktur dan SDM.
